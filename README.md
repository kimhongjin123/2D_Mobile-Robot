# 🤖 로봇 시뮬레이션 프로그램

## 📌 소개

이 프로그램은 모바일 로봇의 이동, 장애물 회피, 충돌 감지를 시각적으로 표현하는 교육용 시뮬레이션 도구입니다. 사용자는 로봇의 위치를 설정하고, 충돌 반경을 조정하며, 다양한 장애물과 상호작용할 수 있습니다. 프로그램은 Python과 Tkinter를 활용하여 GUI 기반으로 구현되었습니다.

## 🎯 주요 기능

- **로봇 위치 지정** 🗺️: 사용자가 직접 위치를 입력하거나 랜덤으로 배치 가능
- **목표 지점 이동** 🎯: 로봇이 사전에 지정된 목표로 이동 가능
- **충돌 감지** 🚨: 로봇의 충돌 반경(회색 원)이 위치에 따라 동적으로 갱신됨
- **장애물 설정** ⛔: 사용자가 장애물과 인플레이션(확장된 충돌 영역)을 설정 가능
- **사용자 입력** ⌨️: 로봇 좌표, 장애물 개수, 충돌 반경을 동적으로 입력 가능
- **로그 시스템** 📜: 실시간으로 로봇의 이동 및 상호작용을 기록

---

## 🏗️ 코드 구조

### 1. **메인 애플리케이션 (`robot_sim.py`)**

이 파일은 시뮬레이션의 핵심 로직을 포함하며, 다음을 담당합니다:

- GUI 초기화 및 이벤트 처리
- 로봇 이동 및 목표 지점 설정
- 장애물 생성 및 처리
- 충돌 감지 및 시각적 표현

### 2. **핵심 기능**

#### 🔄 `randomize_robot_position()`
- 로봇의 위치를 랜덤하게 설정합니다.
- 장애물과 겹치지 않도록 유효한 위치를 찾습니다.
- 충돌 반경을 업데이트합니다.

#### 🎯 `move_to_goal()`
- 로봇을 목표 지점으로 이동시킵니다.
- 로봇의 위치와 방향을 업데이트합니다.
- 충돌 반경이 로봇을 따라 이동하도록 설정합니다.

#### 🔍 `update_collision_range()`
- 충돌 반경(회색 원)이 로봇 중심을 따라 이동하도록 갱신합니다.
- 충돌 범위를 실시간으로 시각적으로 업데이트합니다.

#### ✅ `is_valid(position)`
- 주어진 위치가 장애물과 겹치지 않는지 확인합니다.
- 로봇이 유효한 범위 내에 있는지 검증합니다.

## 📖 사용법

### 🔧 설치 방법
Python과 Tkinter 라이브러리를 설치해야 합니다:

```bash
pip install tk
```

### ▶️ 실행 방법
스크립트를 실행하세요:

```bash
python robot_sim.py
```

### 🕹️ 조작 방법
- **로봇 위치 설정:** 입력창에서 `x, y` 좌표를 입력 후 적용
- **충돌 반경 조절:** 새로운 반경 값을 입력 후 적용
- **랜덤 위치 설정:** "랜덤 배치" 버튼 클릭
- **목표 이동:** "목표 지점 이동" 버튼 클릭
